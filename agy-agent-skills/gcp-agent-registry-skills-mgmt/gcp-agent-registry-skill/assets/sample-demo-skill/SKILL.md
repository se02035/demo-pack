# Registry Smoke Test

Heliograph noon-gun calibration for this package. The distinctive vocabulary
lives only in this body, not in the YAML name or description.

## Purpose

Calibrate a shipboard heliograph so the noon gun can be signaled by mirrored
sunlight at local apparent noon. Use this procedure when a vessel must mark
civil noon for chronometer checks without radio time signals.

## Procedure

1. Level the heliograph tripod on the flying bridge and sight the azimuth mark.
2. Set the index mirror to the computed solar altitude for the ship's longitude
   at estimated noon.
3. Flash a one-second burst toward the forecastle gun crew at the instant the
   sun's lower limb kisses the horizon vane.
4. Log the chronometer offset in the noon-gun signal book.

## Outputs

- A completed heliograph sight reduction slip for the watch.
- The recorded flash-to-gun latency in seconds.
